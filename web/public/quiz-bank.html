Tabel invoegen

Klik op </> om een optie als code-blok in te voeren. Selecteer de correcte optie(s) via de keuzeknop.

Elk open-onderdeel krijgt een label (bv. "Waarde van x") en een eigen tekstveld bij de leerling. Het code-onderdeel (max 1) heeft geen label — het is altijd de gewone, uitvoerbare code-editor. De punten van de vraag zijn de som van de onderdeel-punten.

CSV bulk-import

Volledige kolomvolgorde (header-rij mag, scheidingsteken ; of ,):
onderwerp ; niveau ; type ; punten ; vraag ; keuzes ; juiste ; modelantwoord ; tags ; delen ; onderdelen
• niveau: makkelijk / gemiddeld / moeilijk  •  type: code / open / single / multiple / composite
• keuzes: opties gescheiden met | (enkel bij single/multiple)
• juiste: de juiste optie(s) — tekst of 1-gebaseerd nummer, meerdere met |
• delen: private / school / public  •  enkel vraag is verplicht
• Bij type composite: onderdelen = labels gescheiden met | (leeg op de positie van het code-onderdeel); keuzes = het type per onderdeel als [open;code;...]; punten = de score per onderdeel als [3;3;...] — alle drie in dezelfde volgorde. Max 6 onderdelen, max 1 code-onderdeel. Let op: velden met een ; erin (de arrays) moeten tussen aanhalingstekens staan, anders wordt die ; als kolomscheiding gelezen.
Duplicaten (zelfde vraagtekst) worden automatisch overgeslagen. 

onderwerp;niveau;type;punten;vraag;keuzes;juiste;modelantwoord;tags;delen;onderdelen
