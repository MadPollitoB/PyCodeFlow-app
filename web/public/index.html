PyCodeFlow

Werk samen live aan Python-code in de klas, of start een examenmodus waarin elke leerling individueel werkt terwijl de leerkracht live kan meekijken.

# KLASMODUS # --------- # In deze modus werkt de hele klas samen in één editor. # De leerkracht kan live code aanpassen en iedereen ziet dit meteen. # Je kan hier meestal zelf ook mee typen (als dit toegelaten is). # De leerkracht kan tijdelijk overschakelen naar zelfstandige modus: # Dan krijg je een eigen werkblad om individueel te oefenen. # EXAMENMODUS # ----------- # In deze modus heeft elke leerling een eigen editor. # Je werkt volledig zelfstandig. # De leerkracht kan live meekijken, maar niet ingrijpen.
